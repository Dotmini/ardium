Ardium Compiler 2.2 - Getting Started

Quick Start

After installation, verify the compiler is working:

arc --version

Compile Your First Program

arc build myapp.ar -o myapp
./myapp

Example Program

import CoreUI

fn Main() {
    init_gui()
    create_window("Hello Ardium", 800, 600)
    
    VStack(fn() {
        Title("Welcome to Ardium 2.2")
        Button("Click Me")
    })
    
    run_app()
}
