# Installation Guide

## macOS

1. Download the `Ardium.pkg` installer.
2. Run the installer and follow the instructions.
3. Verify the installation by running:

   ```bash
   arc --version
   ```

## Binary Locations

- **Compiler**: `/usr/local/bin/arc`
- **Runtime**: `/usr/local/lib/libardium.dylib`
- **StdLib**: `/usr/local/lib/ardium/stdlib/`
