## 1. What is Ardium?

**Ardium (v2.3.4)** is a modern, high-performance systems programming language designed to bridge the gap between the raw power of C/Rust and the elegance of high-level application development (Swift/Python).

### Key Philosophy

- **System-Level Performance**: Compiles to native machine code via LLVM.
- **High-Level Syntax**: Clean variable declarations (`var`, `let`), meaningful keywords, and intrinsic support for modern patterns.
- **Hybrid Runtime**: Seamlessly blends manual memory management (pointers) with high-level abstractions (Ref-counted Strings, Arrays).
- **Apple-Native**: First-class support for macOS frameworks (Cocoa, SwiftUI).
