# Introduction to Ardium

Ardium is a modern, high-performance programming language designed for efficient system programming and reactive UI development. It combines the power of low-level control with the ease of high-level abstractions.

## Key Goals

- **Performance**: Compiled to native code via LLVM.
- **Modern Syntax**: Clean and expressive, influenced by Swift and Rust.
- **Reactivity**: First-class support for state management and UI components.
- **Interoperability**: Seamless integration with C/C++ libraries.

## Current Version: 2.1.0 "Evolution"

This version introduces `var`, `enum`, enhanced FFI with `@External`, and reactive `@State`.
